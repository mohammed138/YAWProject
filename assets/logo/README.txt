YAW STUDIO — LOGO FILES
=======================
Concept A · the YW ligature. W = V + V. Y = the centre stem.
Mirror-symmetric about the vertical axis by construction.

FILE                     USE
--------------------------------------------------------------
mark-navy.svg            Main mark. Website, letterhead, deck.
mark-white.svg           On any dark background or photograph.
mark-black.svg           One colour. Stamp, fax, embroidery, engraving.
mark-watermark.svg       All white. Place at CENTRE of the photo,
                         opacity 55-65%. Never in a corner.
icon-slab-navy.svg       Small sizes. Favicon, app icon, 16px.
icon-slab-black.svg      Small sizes, one colour.
avatar-viewfinder.svg    Social profile pictures. Square, fills frame.
favicon.svg              Same as the slab. Already linked in every page.

COLOURS
  Navy   #16265E   everything
  Red    #D6291E   the focus point ONLY — never for text
  Paper  #F4F5F6   knock-out colour inside the slab
  Ink    #111518   one-colour version

RULES
  Clear space  = the height of the red dot, on all four sides.
  Smallest use = 16px / 6mm. Below that switch to the slab.
  Stroke ratio = 18 / 208 of the mark width. Keep it at every size.

NEVER
  Stretch it. Rotate it. Add a shadow or a gradient.
  Recolour the red dot. Put handwriting back inside it.
  Place it over a busy part of a photograph.

TO EXPORT PNG
  Open the SVG in a browser, or:
  npx svgexport mark-navy.svg mark-navy@1024.png 1024:
